## Overview (one minute)

`core_gm` is short, and almost all of it is bookkeeping. Its proof is finite Fourier analysis on an abelian group H (the
Galois group of the host field), followed by a real-variable size lemma. All of the arithmetic content sits in the
hypothesis bundle `CoreAtH`. The heart of that bundle is `SizeData₂ Dd C Xpp`: about eleven real inequalities about one
record `Dd : Data` of real numbers. These are the slopes of Hermitian lattices, the heights of maps, the "gains" at inert
primes, the divisor term `DIV`, and the counts. From those inequalities, `each_unit_bound_statement` derives
**ASK(u) ≤ Main(u) + ErrX(u)**. Here ASK is an explicit prime sum (the formula is in Q1). Main is
m·Σ_t (a_t log a_t − a_t − …): **m copies** of the Chebyshev/Stirling main term, one for each of the m "lifts" j = 1..m. The
error has a one-off part of size ≈ x·b per t and a per-lift part of size ≈ m·b·x^{O(ε)}. `core` then divides by m. The
size lemma `proposition_size_bound` needs x^{1/2−ε} ≤ m ≤ x^{1/2+ε/2}, and this is **where 1/2 comes from**. The error per
unit is ≈ x/m + m, which is balanced at m ≈ √x. So the chain length really is ≈ √x, and each lift adds one copy of the
main term (one more order of multiplicity) at a height cost that grows like m.

The Ш-length bound (`VVle`) does not appear in `core_gm`, `CoreAtH` or `ChainTied`. It enters upstream, where `ChainTied`
is constructed: `HypV` → `vvRecord` → `divinN_of_hypV` → `DIVinN`. There it bounds the excess local divisibility
("etaSum") of each lift, through `LinkN`. `LinkN` in turn comes from a literature bundle of p-adic Hodge theory and local
Galois cohomology (`NLink.Hypotheses₂`).

I found no induction or bootstrap on m, on the level, or on the exponent. The only induction I saw is a structural one
that composes the m maps of a chain (`ChainTie.chain_le`). I found no pigeonhole/Stepanov step in what I read. The closest
analogue is an Arakelov slope inequality (`SlopeIneq`, `height_chain`).

## Q1. `core_gm` and `CoreAtH`: statements, Gm, weights, parameters

**`UpperTheory.Comparison₂.core_gm`** (`Development/AutomorphicArithmetic/PrimitiveCosets/CoreGm.lean:12`) [S, P, read in full]:
```lean
theorem core_gm : ∀ (Λ : Level) (eD eL K cHH eK C eps : ℝ), 0 < eps → ∃ x1, ∀ x ≥ x1, ∀ (φ : Frame) (H : HostAx φ) (TT : Finset φ.A),
    EAtH Λ H.toHostRaw TT x eps C → CoreAtH H.toHostRaw TT eD eL K cHH eK eps x →
      Λ.Gm x ≤ x ^ (1/2 + (eD + eL + 7) * eps)
```
In words: fix a cyclic level Λ (the characters generated by ψ) and constants. For all large x, any host (frame φ, host
H, a finite set TT of elements of the group φ.A) that satisfies the explicit-formula error conditions `EAtH` and the core
bundle `CoreAtH` at scale x has Gm(x) ≤ x^{1/2+(eD+eL+7)ε}. On the main path, `link_gl` instantiates eD = 2 and eL = 0
(`LinkGLOBAL Fm 2 CH 3 2 0`, `Development/AbelianVarietyTheory/Proofs/GlobalInterpolation/LinkGl.lean:14`) [S]. The
exponent is therefore 1/2 + 9ε.

**Gm** (`Formalism/SharpRestriction/RamificationFrobenius/TotientGaloisClasses/ExplicitFormulaErrorOfHostConditions.lean:36-38`) [S]:
```lean
def wt (ψ : PChar) : ℝ := if Λ.psK = some ψ then 1 else (3 * (Λ.o : ℝ) + 1)⁻¹
def Gm (y : ℝ) : ℝ := Formalism.Gz y + ∑ ψ ∈ Λ.Nt, Λ.wt ψ * (An.gChi ψ.χ y).re
```
Gz(y) = Σ_{n≤y} Λ(n)(y/n − 1) − y log y + (1+γ)y (`Gfun`, `LocalRingCardinality/DataParams₂.lean:60`) is the zeta
term. gChi(χ, y) = Σ Λ(n)χ(n)(y/n−1) + y·L'/L(1,χ). The weight is 1 for the exceptional character psK and 1/(3o+1) for
the others. `gmA_eq` (`PrimitiveCosets/GmAEq.lean:61`) [S] identifies Λ.Gm with the finite-group expression
`GmA (arith H) ell (keptA Λ H) (3o+1)⁻¹`. That is a sum over the kept additive characters ψ of E0 × H (E0 = (ℤ/2)²) of
wtA·Re GPsi(ψ, y), where GPsi(ψ, y) = Σ_{n≤y} Λ(n)·primVal(ψ)(n)·(y/n−1) + y·ell(ψ)
(`Formalism/SizeWindowBrackets/FirstPrimeNeSecondPrime.lean:68`) [S].

**`CoreAtH H TT eD eL K cHH eK eps x`** (`PrimitiveCosets/CoreAtH.lean`) [S, read in full] asserts that the following
data exist:
- a finite type U0 with a map `tr : U0 → φ.A` onto the subgroup A0 (the "units"/base points u0);
- for each u0, a nonempty finite type `W u0` (the "words" u);
- a finite type Top ≃ TT;
- naturals m (number of lifts) and f = |PhiSet|;
- a record `Dd : Data U0 W Top m f` of about 40 real-valued fields, and constants `C : Consts`;
- ell (values of L'/L(1)), N, T2 ⊆ A0, weights a : φ.A → ℝ, w : φ.A → Fin m → E0×φ.A → ℝ, η, X', θ;

with the following properties:
- `HostAddCharCompatible H ell`: ell ψ = L'/L(1, χ) for the primitive χ attached to ψ;
- Dd.x = x, Dd.ε = eps, C.eDiv ≤ eD, C.eLoss ≤ eL, C.cHH ≤ cHH;
- `IdentU`: Dd.aT = a, Dd.w = w, Dd.gam = γ, Dd.LpL = Re ell(chC), and Dd.ASK u = Σ_{t∈TT} Σ_{j<m} ASK(a_t, t, w(tr u, j));
- **`SizeData₂ Dd C Xpp`**, the arithmetic content (see Q2);
- `ErrWindows`, `BNBoundsU`, `SizesA`, `ThinScales`, `CostWindows`, **`RestSize`** and T2 ⊆ A0, which are size conditions.

`RestSize ε x n nT nT2 m b k aE` (`Formalism/SizeWindowBrackets/SChain.lean`) [S] is:
```lean
aE ≤ 2*x*b ∧ x^(-(ε/8))*n/2 ≤ nT ∧ x^(-ε) ≤ nT2/n ∧ x^(1/2 - ε) ≤ m ∧ k ≤ n^2 * x^(1/2 - ε)
```
**The chain length m is at least x^{1/2−ε}.** This hypothesis encodes "chain of length ≈ √X". [S]

**Parameters.**
- **x** is the window point. **ε** is the slack.
- **a ≈ x·b** with **b = exp(L)** and **L = x^ε**. `DivIneqRecord` has the hypotheses `L = x^eps → b = exp L → a = x*b`
  [S], and `SizeData₂.aT_win` puts a_t in [a, a(1 + 1/(k x^{A/2}))] [S]. So the "prime sum length" a_t is astronomically
  larger than x. Everything is measured in units of b, and the role of x is the ratio a/b.
- **m** = D.R.m is the number of lifts (`lifts D = Finset.Icc 1 D.R.m`, `LocalRingCardinality/DataParams₂.lean:208`) [S].
- **k** = D.R.k is a second rank parameter, with x·m ≤ k ≤ n²x^{1/2−ε} [S].
- **n** = |H|, nT = |TT|, nT2 = |T2|.
- **eD, eL** bound the exponents C.eDiv and C.eLoss of the x^{O(ε)} losses in `DIV` and `Losses`.
- **The page e(x), field E, primes q and d** do not appear in `core_gm` or `CoreAtH`. They appear only in the host/family
  data (`Fm.D x i : D7`: `.host.q`, `.host.d`, `.host.E`, `.R.t`) and in `HypV` (next section). In `ArithData`, `d` is
  the auxiliary prime with `Inert p :⇔ (p/d) = −1`, and q1 is the other ramified prime (`HostFactsS`,
  `DedekindLFunctions/SplitInertia.lean:14`) [S].

**`EAtH`** comes from the good pairs (`analytic-core.md` Q3). It supplies:
- `charsA` (`PrimitiveCosets/charsA.lean:80`) [S]: TT is equidistributed in the kept characters with error
  M·x^{−1+ε}·|TT|, and |ell ψ| ≤ C log x for non-kept ψ;
- `sigA_le` (`PrimitiveCosets/SigALe.lean:38`) [S]: Σ_{non-kept ψ} |GPsi(ψ, x)| ≤ 4·o·x^{1/2+ε}. This is the square-root bound
  for the **twisted** characters, from `PairGood.bounds`.

```lean
def ASK (τ) (a) (w) := (∑' p, if Inert p then 2 * log p * ∑' i, if Odd i then max (a / p^i - w (partner τ (frob p ^ i))) 0 else 0 else 0)
                     + log d * ∑' i, max (a / d^(i+1) - w (partner τ (gd (i+1)))) 0
def MAIN (a) (w) := a * (log a - 1 - γ + κ(prim ch).re - f⁻¹ * ∑ ρ ∈ Phi, log (w ρ))
```
**ASK is the prime sum.** It runs over primes p inert in ℚ(√±d), with 2 log p weights and odd prime powers, and counts
the positive parts (a/p^i − w)⁺, where the threshold w depends on the Frobenius class of p^i in H. Without the w this is
the shape of Legendre's formula: log(a!) = Σ_p log p Σ_i ⌊a/p^i⌋. MAIN is its Stirling-type main term
a log a − a + (constants) [S for the formulas; the Legendre/Stirling reading is mine, N].

**`ch_core` mechanism** [P, `CharacterBalanceMoves.th_le`, `one_char`, `core`, `sum_Th`]:
1. **`ch_balance`** (`ChBalance.lean:200`) [S name only, N for content] rewrites ASK − MAIN through the explicit formula as
   Th + (small). Th(u0, t) = |Phi|⁻¹ Σ_{s∈T2} Σ_ψ ψ(−e1(s+u0−t))·b·GPsi(ψ, a_t/b). It is a Fourier-weighted combination of
   the GPsi at the point y = a_t/b ≈ x.
2. **`th_le`** compares the weights w(u0, j, ρ) with the constant b. On the "thick" set the weights are in [b, b+η+1] and
   `LipW` makes the difference small. Off it the weights are ≤ 2b' and `ThinScales` bounds GPsi at the large argument
   a/w ≥ X'/3 by (a/w)·θ. `CostWindows` turns these losses into ≤ 2b/x per (t, j).
3. **`core`** averages over u ∈ A0 (`sum_A`, `sum_Th`, orthogonality of characters on the subgroup A0). The output is
   |TT|·m·b·(δ2/2)·Y ≤ Err + 2|TT|mb/x, where Y is a lower bound for Σ_t Σ_{ψ∈PsiA A0} ψ(e1 t)·GPsi(ψ, a_t/b).
4. **`one_char`** turns that into Y ≥ (GmA − SigA) − 4x^{1/2+ε}. It moves a_t/b to x (`move`, `DerivInt`) and uses the
   equidistribution of TT (`CharsA`) to replace Σ_t ψ(0,t) by c·|TT| for kept ψ.
5. **`proposition_size_bound : GrowthSizeBound`** (`Formalism/SizeWindowBrackets/ChainSlopeWindows/LipschitzWeightAndMinimum.lean:507`)
   is pure exponent arithmetic. I read its `have` skeleton. Its statement is in
   `Formalism/SizeWindowBrackets/GrowthBoundGivesRiemannHypothesis.lean:109-121` [S]:

- **Where the Ш bound enters** [S, P]. `HypV Fm := ∀ large x, ∀ i, VVle (Fm.D x i).host.E (Fm.D x i).R.t (sqrt (Fm.L x i).sc.b)`
  (`CharacterBoxes/DivinNOfHypV.lean`). `vvRecord` turns VVle into Σ_ℓ vvTerm(ℓ) ≤ √b, where
  vvTerm(ℓ) = log ℓ·Σ_{1≤e<t} shaLen_ℓ(e). `divinN_at` and `divinN_of_hypV` combine this with **`LinkN`**:
  ```lean
  def LinkN_at L j C := Summable (vvTerm D) →
    etaSum L j ≤ dZ0 j * (C * (f * m * b * L^2 + log x^2 * Nc) + ∑' l, vvTerm D l)
  def DIVinN_at L j C := etaSum L j ≤ D0 * (C * x^eps * (B0 + Nc))      -- B0 = f·m·b·x^ε
  ```
  etaSum L j = Σ_{w twisted} lwP(w)·ramIdx(w)·etaJ(j, w), where etaJ is a local length of a quotient of lattices for
  the j-th lift (`Divisibility/LiftLat.lean:116-147`: `etaW w := locLen w (Tl ℓ Z) (cutZ ℓ Z)`) [S]. So, for each lift
  j, **excess local divisibility at the twisted places is bounded by the Ш lengths plus O(f·m·b·x^{2ε})**. Since √b ≪ b,
  the Ш contribution is lower order. The bound only has to hold at scale b = e^{x^ε}.

  (`ThirdPlaceSeries/At23OfAll.lean`) with `P.nLink : GlobalTheory.NLink.Hypotheses₂`

  (`LevelLetterCocycles/ThetaScalarFamilyOfEigenvalue.lean:37`, `StatementFamilies/ExportFamilies.lean`) [S].
- **`DIV`** comes from `LinkDIV_at`'s clause muDual + h u − Fo ≤ MAIN u + C·nT·a·La + C·m(B0+Nc)·x^{Cabs·ε}
  (`GlobalTheoremInputs.lean`) [S]. That in turn comes from `LinkDIVt` (`LinkEta → DIVinN → LinkDIV`), which

  ν!-type term (my gloss). Summing over the m lifts produces the factor m in front of ph(a_t).

## Q3. The mechanism, and the "one more lift, one more order" lemma

The mechanism as concretely as the source states it. Write a ≈ x·b with b = e^{x^ε}.

1. **Prime sum → local gains (lower bound).** `LinkG` gives Σ_j gain_j(p) ≥ Σ_j Σ_t vonMangoldtClassSum_j(t, p) − errors
   at each inert prime p ≤ X''. After the p-adic weights (sz, lw·ramIdx summing to log p, `FactEtaMean`), this gives
   Ga ≥ ASK − LoP (`LossBounds`).
2. **Local gains → global slope (upper bound).** The gains enter the slope of the lattice Nu
   (`QuotientSlopeBoundsWith`: muN ≥ muM + Ga + Fo − Ee − Lo). `SlopeIneq` gives a lower bound on the dual slope muCC in
   terms of the average slope s. `DIV` bounds muCC + h − Fo above by the main term m·Σ_t(a_t log a_t − a_t − a_t logΩ) − Σ_t
   a_t log T. Combining gives Ga ≤ Main + ErrX.
3. **Multiplicity.** The main term carries the factor **m**: one copy of a log a − a per lift. In `DivIneqRecord` it
   arises as Σ_j hK_j with hK_j ≤ Σ_ρ ph(ν_jρ), and ν_jρ ≈ a_ρ + k·w_jρ for **each** j [S]. So the precise form of "each
   theta lift wins one order of multiplicity" in the source is that **each of the m lifts contributes its own multiplicity
   vector ν_j ≈ a + k·w_j, and hence its own copy of ph(a) in the divisor bound, and its own copy of the prime sum in
   ASK = Σ_t Σ_j ASK(a_t, t, w_j)**. The thresholds w_j differ across lifts. This is how Frobenius classes are separated
   (the `partner τ (frob p^i)` argument).
4. **The divisibility of each lift by Ш.** `LinkN`/`DIVinN` bound the excess local length etaJ(j, w) of the j-th lift at
   the twisted places by Ш¹ lengths + O(f·m·b·x^{2ε}). This is a divisibility statement of the form "local index of lift
   j ≤ global Selmer/Ш size". I did **not** find a lemma "lift j+1 is divisible by one more power than lift j". There is no
   declaration `ChainIntM` in the tree (grep found none). The nearest objects are:
   - `ChainTie` / `KerChain` / `ColChain` (`DivisionHeightBoundStatement.lean:248-404`): a chain of linear maps between
     form spaces, Q.step j : (F j).Forms → (F (j+1)).Forms;
   - `ChainTie.chain_le`: composing the chain matrices equals `colTo` (proved by induction on i);
   - `height_chain`: the height of the composite is at most the sum of the step heights.

   So "one more lift" adds one more step to a composite map, with one more height term hK_j, and one more multiplicity
   vector ν_j.
5. **Why 1/2.** After `core` divides by |TT|·m·b·(δ2/2), the error is the following [S, from `SizeWindows` and the
   `proposition_size_bound` skeleton]:
   - nT·aE·(1+m²/k)/(nT·m·b) ≈ x/m (one-off losses of size x·b per t: the a·La and a·log T terms);
   - m·(2n·m·b·x^ε)/(nT·m·b) ≈ m·x^{O(ε)} (per-lift losses B0 = f·m·b·x^ε, accumulated over m lifts);
   - nT2·k·b·x^{2ε}/(n²·nT) ≈ k/n² ≤ x^{1/2+O(ε)}.

   With x^{1/2−ε} ≤ m ≤ x^{1/2+ε/2} each term is ≤ x^{1/2+13ε/8}, and the proof concludes Gx ≤ x^{1/2+(C+3)ε}. Square-root
   cancellation is therefore produced by **balancing x/m against m**. The signal grows linearly in the number of lifts.
   The cost of each lift (its height/size budget B0) also grows linearly in m, so the total cost grows quadratically.
6. **Pigeonhole/Stepanov, determinant.** I found no explicit pigeonhole, Siegel-lemma or vanishing-to-high-order
   auxiliary construction in what I read. Possible relatives:
   - `SlopeIneq` is an averaging lower bound for a dual slope, with the log(1+HH/uF) entropy term;
   - the slope/height formalism (`Formalism.HN.htMap`, `opNormAt`, muMax/muDual) is Arakelov geometry of Hermitian
     lattices, i.e. a slope method;
   - `stepDiiiRecord` lives in a namespace called `Formalism.BranchingDeterminantCap`, which suggests a determinant [N].
     I did not open it.

## Q4. Induction or bootstrap?

None at the level of `core_gm`, `ch_core`, `ch_top`, `each_unit_bound_statement`, `proposition_size_bound`, `ChainTied`,
